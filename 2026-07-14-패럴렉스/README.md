# 7월 14일 패럴렉스 효과

## 파일보는방법

잘 안되면 카톡으로 알려주세요.

## 넣는 위치
워드프레스 관리자 → Code Snippets

## 사용 방법
1. 코드 파일을 엽니다.
2. 오른쪽 위 복사 버튼을 누릅니다.
3. Code Snippets에 붙여넣습니다.
4. 저장 후 활성화합니다.


## 편집화면에서 적용방법
글씨에는 story-text 클래스만 넣고, images-2 클래스를 추가하면 이미지 2개에 관련된 글씨입니다.
넣는 방법은 story-text images-2 이렇게 넣고, 
윗줄에 적은것처럼 두 글씨 사이에는 띄어쓰기가 꼭 있어야합니다.

이미지에는 story-image 클래스 하나만 넣으면됩니다.

이미지와 글씨 나오는 순서는 편집화면에 넣은 순서대로입니다.
